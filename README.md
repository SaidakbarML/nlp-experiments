# NLP Experiments

A collection of natural language processing experiments and trained models.

## Why this exists
Space for exploring NLP techniques and model training, deployed via AWS Elastic Beanstalk configuration (`.ebextensions`).

## Tech stack
Python, Jupyter Notebook

## How to run
Explore the notebooks in `notebooks/`. Trained artifacts are stored in `models/`. The `.ebextensions` folder configures deployment to AWS Elastic Beanstalk if you want to deploy it as a service.
